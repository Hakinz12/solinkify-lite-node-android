# Solinkify Lite Node (Android)

An Android implementation of the Solinkify Lite Node runner, built with Kotlin.

## 📖 Overview

This project ports the Solinkify Lite Node runner to Android, allowing Android devices to participate as Lite Nodes within the Solinkify network.

## ✨ Features

- ✅ WebSocket communication
- ✅ Challenge authentication
- ✅ Relay job handling
- ✅ Base64 transaction decoding
- 🚧 Solana RPC integration (in progress)
- 🚧 Material 3 dashboard (planned) 

## 🛠️ Tech Stack

- Kotlin
- Android Studio
- OkHttp
- Gson
- Material 3
